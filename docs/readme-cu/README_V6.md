# Lịch Sử Đảng Cộng Sản Việt Nam — V6 Source Based

Web tĩnh: HTML + CSS + JavaScript + JSON-like JS data. Không cần backend/CSDL.

## Navbar
TỔNG QUAN | LỊCH SỬ | TỔ CHỨC | ĐỀ CƯƠNG | TRẮC NGHIỆM

## Tách nguồn dữ liệu
- `data/history-official-v6.js`: hồ sơ lịch sử dựa nguồn chính thức.
- `data/history-integrated.js`: khung thời kỳ, phong trào, khái niệm.
- `data/leader-bios-v6.js`: sơ yếu lý lịch Tổng Bí thư.
- `data/organization-dashboard.js`: tổ chức và lãnh đạo hiện hành.
- `data/syllabus.js`: 40 vấn đề đề cương Word, chỉ dùng ở Đề cương.
- `data/quiz.js`: 250 câu trắc nghiệm.

## Chạy local
Mở `index.html` bằng Edge/Chrome. Khuyến nghị dùng Live Server khi phát triển.

## Deploy
Có thể dùng GitHub Pages/Vercel/Netlify. Vì toàn bộ đường dẫn nội bộ là relative, không cần backend.
