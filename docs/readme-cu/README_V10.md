# LSĐCS — V10 Deep Complete

Bản V10 lấy V9 DeepResponsive làm nền và khôi phục các yêu cầu giao diện tốt của V7, đồng thời mở rộng nội dung lịch sử theo đủ 11 thời kỳ.

## Chạy

Mở `index.html` trực tiếp để xem nội dung. Để QR và các tài nguyên online hoạt động đầy đủ, chạy qua local web server hoặc deploy HTTPS.

Ví dụ:

```bash
python -m http.server 8000
```

Sau đó mở `http://localhost:8000`.

## Các file V10

- `data/period-expert-v10.js`: nội dung chuyên sâu 11 thời kỳ.
- `assets/css/patch-v10.css`: responsive, slider, Tuyên ngôn card, war timeline, footer.
- `assets/js/patch-v10.js`: carousel, layer lịch sử, ảnh fallback, “Đồng chí”, footer.
